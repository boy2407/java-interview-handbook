# java-interview-handbook

Java Backend interview handbook (Vietnamese). One markdown source builds both the VitePress website and the Word file.

## Content
- Single source of truth: `content/*.md`, written per `tools/FORMAT_SPEC.md` (limited markdown syntax, callout labels, question format, tone).
- `docs/*.md` (except `docs/index.md`) and `docs/.vitepress/nav-data.json` are generated by `tools/prepare-docs.mjs`; never edit them by hand.
- Prose is Vietnamese; **all code comments (in handbook code samples and in repo code) are English**.
- Check Java samples with `python3 tools/check_java.py content/<file>.md --run`.
- Build: `npm run docs:build` (website), `npm run docx` (Word file into `docs/public/`).

## Git conventions
- **Commit messages are always written in English** (imperative subject ≤ 72 chars, body explains why), even though the content is Vietnamese.
- Commit and push as GitHub account **boy2407** (repo-local git identity is configured; `gh auth status` must show boy2407). Never use the `rabbitCanCode` account.
- Pushing `main` triggers `.github/workflows/deploy.yml`, which deploys to https://boy2407.github.io/java-interview-handbook/.
